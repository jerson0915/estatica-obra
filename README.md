# Estática, del cuaderno a la obra

Apuntes de clase de **Construcción de obras civiles** convertidos en una página interactiva: seis estaciones con simuladores, cada una con un ejemplo de dónde aparece el tema en una obra real.

🔗 **Ver la página:** https://jerson0915.github.io/estatica-obra/

1. Qué es la estática
2. Unidades y conversiones (sistema internacional e inglés)
3. Suma y resta de vectores
4. Composición de vectores: resultante y equilibrante
5. Ecuaciones de equilibrio: reacciones de una viga
6. Todo junto: izaje de una viga con eslingas

Al final hay ejercicios de práctica con su respuesta.

Simulador de estudio: los valores de obra son de referencia para aprender; en una obra real manda el diseño del ingeniero.
